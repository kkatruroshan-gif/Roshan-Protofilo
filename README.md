# Katru Roshan Portfolio

Animated light-theme React portfolio for Render, packaged as a Docker web service.

## Run locally

```bash
npm install
npm run dev
```

## Build locally

```bash
npm install
npm run build
```

## Deploy on Render

1. Push this folder to a GitHub repository.
2. Render → New → Web Service → connect the repository.
3. Select **Docker** as the environment.
4. Leave Root Directory, Build Command, and Start Command blank.
5. Deploy. Docker builds the Vite app and serves it through Nginx on port 10000.
